# 팀 역할과 협업

백엔드는 회원·AI 채팅·관리자 기능을 나누고, 프론트엔드는 화면과 API 연동을 담당합니다.

| --- | --- | --- | --- |
| 임재홍 | `sarguments` | 백엔드 관리자 | 회원·세션·대화·시스템 로그 조회, DB 연결, 관리자 JWT 권한 검사, 역할 변경·초기 관리자 시드, 공통 오류·CORS |
| 양승조 | `ted1117` | 백엔드 AI·채팅 | 대화 모델·저장·소유권·문맥, 질문 전송·삭제, AI 예외·재시도·타임아웃, 1,000자 검증·통합 테스트 |
| 김병철 | `andy1398` | 백엔드 회원 | 회원가입·검증·비밀번호 해싱, 로그인·JWT, 토큰 폐기 로그아웃, 내 정보 조회, 가입·로그인 이벤트 구분 |

## 협업 방식

1. 최신 `main`에서 기능·수정·문서별 브랜치를 만듭니다.
2. PR에 요약·변경 사항·참고 사항을 작성합니다.
3. 리뷰어 1명 이상의 승인을 받고 검사 결과를 확인한 뒤 `main`으로 병합합니다.
